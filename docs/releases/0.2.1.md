# WorkLog 0.2.1

- Retomar um timer pausado continua a mesma sessão, preservando o histórico e somando somente os ciclos trabalhados.
- As sessões agora mostram o início, o fim e a duração de cada ciclo.
- É possível editar os horários de cada ciclo com precisão de segundos. A edição valida conflitos, preserva as pausas e recalcula o total.
- Totais, relatórios, backup e sincronização passam a considerar os ciclos da mesma sessão, inclusive após retomadas.

Validação: 174 testes, build local e teste manual aprovado pelo usuário antes da publicação.

Distribuição: versão 0.2.1, build 13, para Apple Silicon e Intel. Mantido o requisito de macOS 26.5.

Atualização assinada para o Sparkle. O aplicativo mantém a assinatura ad hoc das versões anteriores, sem notarização Apple.
