# WorkLog 0.3.0

- Projetos podem cobrar em real, dólar ou euro. Os cartões mostram as três moedas e guardam a preferência de destaque por projeto.
- A conversão usa o último fechamento da PTAX de venda do Banco Central. O app consulta a cotação diariamente e mantém a última taxa salva quando a conexão falha.
- Relatórios e exportações mostram subtotais por moeda. Cada fatura preserva a moeda e os valores da emissão.
- A versão para Windows 10/11 inclui o painel estilo notch, relatórios, faturamento e backup compatível com o macOS.

Projetos e faturas antigos são migrados para BRL. O backup v3 pode ser usado entre macOS e Windows e aceita a importação de backups v1 e v2. Para sincronizar registros em dólar ou euro por pasta, atualize todos os Macs que usam a pasta.

O macOS recebe a versão 0.3.0, build 14, para Apple Silicon e Intel, com o requisito de macOS 26.5. Para Windows x64, há um instalador e uma versão portátil.
